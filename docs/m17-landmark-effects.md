# M1.7 地标动态第二批

本次把单个“今日主线任务”动态样板扩展到全部七个地图地标。保持原有七个 React Router 链接、路由、中文文本与 Mock 数据标识。

- 所有地标共享 AnimatedLandmark 的 Motion 悬停和键盘焦点反馈。
- PixiJS 同时只装配一份 Canvas，优先渲染当前交互地标；无激活状态时保留主线任务少量环境金色粒子。
- 七种粒子色调对应任务、项目、消息、日历、快速录入、支线及成长。
- 关闭动效、本地开关记忆、系统减少动效、页面不可见暂停等行为不变。
- 美术独立的旗帜、卷轴、横幅 Sprite 尚未入库；这一批只实现动态逻辑和颜色样板，不能宣称完成美术素材替换。

验收时检查鼠标悬停与键盘 Tab 聚焦各地标，确保没有文字遮挡和 WebGL Canvas 堆积，也不得因粒子出现而伪造任务完成状态。
