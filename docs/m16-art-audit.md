# WorkHub M1.6 美术资产盘点与第一批验收

## T02 资源分类

- backgrounds：地图、原生人物场景和侧栏背景
- frames：九宫格金属框、装饰角饰
- icons：全局导航游戏化图标
- badges：地图盾牌、羊皮纸、成就徽章
- rewards：宝箱与奖励图
- decorations：发光路径与装饰线

以上目录采用小写英文和连字符命名。业务文字、状态、任务进度、链接始终由 React 组件负责，不嵌入图片。

## T03 资源加载与校验

`npm run art:verify` 校验三个现有场景 WebP 的 SHA-256、人物场景 Git 内容摘要和 WebP 头部。Playwright 检查新场景路径、真实加载、尺寸及失败提示，缺图不能悄悄切换成 SVG。
