# M1.7 左侧导航美术精修

依据设计稿，替换普通 Lucide Compass 为 WorkHub 专属八向金色罗盘纹章（SVG，双圆环、金属渐变和中心针），保留品牌文字。选中态使用金色镶边、双层金属填充与两端削角，替代普通矩形管理后台高亮。未选中项保持统一金色细线图标，避免过度炫光。

## 范围与边界

- 仅修改 `AppShell`、新增 `CompassRoseMark` 和 `m17-sidebar.css`。
- 不修改主页浮岛地图、七地标独立坐标和文字安全区、PixiJS 特效、其他业务模块。
- 侧栏选中态由 React Router 的 NavLink 驱动；焦点可见，伪元素不可拦截点击。
- 1440px 与 390px 浏览器专项截图，检查 Logo、金色选中态以及路由切换。
- SVG 是专门绘制的可维护纹章，不是原稿 1:1 像素裁图，视觉最终以用户验收为准。
